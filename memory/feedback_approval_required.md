---
name: Always wait for approval before making changes
description: User must explicitly approve before any code edits or file writes are made
type: feedback
---

Do not make any code changes (edits, writes, new files) until the user explicitly approves the proposed plan.

**Why:** User wants to review and approve all changes before they are applied.

**How to apply:** Always present what you plan to change and wait for the user to say "yes", "do it", "go ahead", or similar before touching any file.
